# 24 — Verified external dataset research and task fit (2026-10-28)

## Scientific scope
OVERRIDE primarily predicts token spans **in the current user turn**, conditioned on preceding dialogue, with separate value and cue layers. It optionally resolves references and derives state operations. Standard Dialogue State Tracking (DST) and coreference datasets have **related but different** gold annotations; they are **not** drop-in gold for OVERRIDE. Literature DST joint-goal accuracy (JGA) must **never** be called OVERRIDE exact-span F1.

## Decisions and non-equivalences
- Keep **SGD as the declared main dataset** (the user's P2 registration). Frames is optional supporting/transfer corpus, not silently replacing SGD.
- Recommend **gold dataset V1**: independent human-reviewed SGD for training, development, and locked test; **Frames challenge** as extra difficult cross-source test *only if* official raw files, licenses and new annotation passes are secured. If Frames isn't acquired, don't claim it was used.
- Since previous 100 SGD pilot utterances were already examined by AI, **none qualify as a never-seen prospective primary test**. Reserve them for training/dev pilot only, even if unlabeled.
- Directly relevant methodological work: SOM-DST (state operation prediction, memory overwrite); TripPy (current-turn span, system memory, cross-slot copy). Both study DST, not the same exact OVERRIDE task.
- Source links are bibliographic evidence, not evidence that our code executed on the corresponding raw data.

## Acquisition / legal gate
1. Pin source repo to immutable commit; save `git rev-parse HEAD` and SHA256 for each raw file. For Microsoft Frames, obtain data from official portal following terms; **never automate agreement bypass**.
2. Store under `data/upstream/` (not public GitHub until permission reviewed). Validate source schema and dialogue IDs before any label conversion.
3. Record dataset ID, exact version, original author citation, license; if unknown, mark `LICENSE_REVIEW_REQUIRED` and avoid redistributing raw/derived records.
4. Every derived OVERRIDE record must keep `origin_corpus`, `origin_split`, `dialogue_family_id`, turn index, extraction methodology, original raw hash, and annotation provenance.

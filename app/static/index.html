About OVERRIDE

NLP Project 2 · token classification · Team Developers

When users change their minds mid-conversation ("Actually, make it 7 pm at the same place"), an assistant has to find which words signal the change, what the new value is, and what points back to an earlier turn. OVERRIDE labels every word of the user's turn with that revision role, in two BIO layers.

Data

1,220 user turns selected from Google's Schema-Guided Dialogue corpus and labeled by two annotators, blind to each other (34,522 word-level labels, agreement 0.86 / 0.81). 363 turns from other SGD splits were locked as a test set before any model existed.

Model

DeBERTa-v3-base with two token heads (VALUE, CUE), selected by grouped 5-fold cross-validation and frozen as a 3-seed ensemble. Locked test: S 0.768, above a CRF (0.735), rule baselines (0.41–0.47) and a zero-shot decision model (0.02).
